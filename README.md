# 窗口尺寸助手 · WindowSizeKeeper

跨显示器拖动窗口时，**保持窗口的物理尺寸不变**。

一台笔记本（3200×2000 @ 200%）加一块外接屏（1920×1080 @ 100%）时，同样一个 600 像素宽的窗口，在笔记本上是 6.4 cm，在外接屏上是 16 cm —— 差 2.5 倍。Windows 只保证"逻辑尺寸"与缩放比例匹配，不管物理大小，所以要靠这个工具做换算。

实测：同一个窗口连续跨屏两次，物理尺寸 82.8 × 62.4 mm → 82.8 × 62.4 mm → 82.8 × 62.4 mm，误差小于 0.1 mm。

---

## 快速开始

1. 下载 `dist/WindowSizeKeeper.exe`
2. 放到一个**长期保留**的文件夹（例如 `D:\Tools\WindowSizeKeeper\`），双击运行
3. 任务栏右下角出现蓝色小图标，即可使用

程序常驻托盘，不显示主窗口，不联网，不写系统目录，也不安装服务。它不安装全局鼠标钩子，也不接管任何软件的右键菜单。

> 想让它开机自动启动：右键托盘图标 → **开机自动启动**，勾上即可。
> 以后即使把 exe 挪到别的文件夹，程序每次启动都会自动把自启项修正到新路径。

## 使用方法

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + S` | 把当前窗口设成该软件记录过的尺寸（没记录就用 24 × 15 cm） |
| `Ctrl + Alt + D` | 把当前窗口的尺寸记为该软件的基准尺寸 |
| `Ctrl + Alt + C` | 把当前窗口移到本屏居中（不改变尺寸） |
| `Ctrl + Alt + K` | 开关"跨屏自动保持尺寸"（默认开） |
| `Ctrl + Alt + Q` | 退出 |

任务栏图标右键菜单里还有：**窗口工具**（本屏居中 / 移到左屏并居中 / 移到右屏并居中 / 适应本屏大小）、开机自动启动、热键说明。

### 典型用法

**用法一：自动（推荐）**

开着"自动保持"，直接把窗口从笔记本拖到外接屏 —— 窗口会自动被修正成同样的物理大小，反向拖回来也一样。如果目标屏装不下这个窗口，会自动缩到该屏工作区内；再拖回大屏时恢复原来的物理尺寸。

**用法二：一键套用固定尺寸**

1. 把某个软件的窗口调到你觉得舒服的大小，按 `Ctrl + Alt + D` 记住
2. 以后这个软件窗口乱了或者换了屏，按 `Ctrl + Alt + S` 一键恢复
3. 尺寸按物理毫米记，所以两块屏上看起来一样大

## 数据文件

`sizes.txt` 与 `log.txt` 都生成在 **exe 所在目录**。

`sizes.txt` 格式：

```
# process=width_mm,height_mm
wechat=260.0,170.0
excel=320.0,200.0
```

进程名用小写（任务管理器里看到的 exe 名去掉 `.exe`）。可以直接手动改，重启程序生效。

## 从源码构建

需要 Windows 自带的 .NET Framework 4.x 编译器（Windows 10 / 11 默认已安装），无需 Visual Studio、无需联网。

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物写入 `dist\WindowSizeKeeper.exe`，并打印文件大小与版本号。

构建参数要点：

| 参数 | 原因 |
|---|---|
| `/target:winexe` | 双击不弹黑框 |
| `/codepage:65001` | 源码是 UTF-8，中文菜单不乱码 |
| `/win32icon` | 嵌入 `assets\app.ico` |
| `/win32manifest` | 嵌入 PerMonitorV2 DPI 声明，否则拿到的坐标是缩放后的假值 |

## 实现要点

- 每 400 ms 枚举一次普通顶层窗口，读取位置、尺寸与所在显示器的有效 DPI
- 用窗口标题栏左上角附近的**锚点**判断"在哪个屏"，而不是"和哪个屏相交面积最大"；窗口骑在两屏交界处时不会来回改尺寸
- 检测到跨屏时，按 `物理尺寸 = 像素 / DPI` 反算目标像素，再延迟 250 / 800 ms 各校正一次
- 目标屏工作区装不下时自动收缩，并保证窗口移进可见区域；拖回原屏后恢复原物理尺寸
- `SetWindowPos` 带 `SWP_ASYNCWINDOWPOS`，目标程序忙时也不会卡住本工具的界面线程
- 用户手动调整窗口大小后，新尺寸自动成为该窗口的基准
- 只处理普通顶层窗口：跳过最小化、最大化、无标题、工具窗口、本程序自己的窗口
- 单实例：用命名互斥量保证重复双击不会起第二个进程
- 自启项写在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，仅当前用户，不需要管理员权限

## 资源占用

空闲时常驻内存约 33 MB（私有内存约 24 MB），CPU 基本为 0；只有真正跨屏改尺寸时才写一行 `log.txt`。

## 注意

- 对 UWP / 微软商店应用无效（它们由 Windows 自己管理，通常本来就不会变）。
- 如果某个软件把窗口尺寸写死在代码里、跨屏后会重置，可能会和它来回拉锯 —— 遇到就关掉自动模式，改用 `Ctrl + Alt + S` 手动一键。
- 以管理员权限运行的程序无法被调整，这是 Windows 的 UIPI 限制。
- 删除整个文件夹即等于卸载；记得先在托盘菜单里取消开机启动。

## 已知取舍

跨屏后**内容布局会变**：物理尺寸不变意味着 200% 的屏上像素尺寸翻倍，界面元素数量不变但更清晰；100% 的屏上像素尺寸减半，可见内容变少。
如果你更希望"内容量不变、只是整体变大"，那就不要用这个工具，改用 Windows 原生的 DPI 感知（把笔记本缩放设为 250% 可与外接屏完全对齐）。
